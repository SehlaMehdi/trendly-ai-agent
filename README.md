# Trendly AI Customer Support Assistant

An AI-powered customer support assistant built for Trendly. The assistant helps customers with order tracking, returns, refunds, exchanges, shipping, and policy-related questions using Trendly's policy document and order data.

# 🚀 Getting Started

## Prerequisites

- Node.js v18 or above
- A Groq API Key

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key
PORT=3000
```

---

## Installation

Clone the repository.

```bash
git clone https://github.com/SehlaMehdi/trendly-ai-agent
cd trendly-ai-agent
```

Install dependencies.

```bash
npm install
```

Run the application.

```bash
npm start
```

or

```bash
node backend/server.js
```

The application will be available at:

```
http://localhost:3000
```
